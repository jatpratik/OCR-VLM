## ⚠️ Audit: Schema vs PDF Mismatches

### Fields in Schema but NOT in PDF (System/Internal Fields)
These are database/system fields that won't be extracted from PDF:

| Schema Path | Type | Reason Not Extractable |
|-------------|------|------------------------|
| `applicationId` | ObjectId | System reference - generated by application |
| `documentId` | ObjectId | System reference - generated by document upload |
| `extractedText` | String | Internal storage for raw OCR text |
| `createdAt` | Date | System timestamp |
| `updatedAt` | Date | System timestamp |

### Fields in Schema but MISSING from Empty PDF Template
These fields exist in the schema but were NOT found in the "All empty (1).pdf" BTL template:

| Schema Path | Type | Notes |
|-------------|------|-------|
| `applicationType` | String | Not visible in BTL template; may exist in other form variants |
| `valuationForFinancePurposeHPP` | Object | Entire HPP valuation section missing from BTL template (schema uses same valuationForFinancePurposeSchema) |

### Fields Found in Filled PDFs but Not in Empty Template
Observed in "Ashok.test" and "All yes fields" but NOT in empty BTL form:

- **Comparable Evidence Table** - Sales and Lettings comparables (not in schema)  
- **Application Type checkbox** (Purchase/Refinance) - partial visibility in some reports

### Recommendations

1. **For `applicationType`**: Add to field mapping - extract if present, else set to `null`
2. **For `valuationForFinancePurposeHPP`**: Map identically to `valuationForFinancePurpose` - extract if HPP section present
3. **For system fields**: Skip during extraction - will be populated by application code

## Notes for LLM Extraction

### Checkbox Detection Rules
- `[X]` or `☒` = **true**
- `[ ]` or `☐` (empty) = **false**
- Not visible/applicable = **null**

### Date Conversion
- Input: `DD/MM/YYYY` (e.g., `27/11/2024`)
- Output: `YYYY-MM-DD` (e.g., `2024-11-27`)

### Currency Conversion
- Remove `£` symbol and commas
- `£ 239,120` → `239120`

### Area Conversion
- Remove `m²` suffix
- `58 m²` → `58`
